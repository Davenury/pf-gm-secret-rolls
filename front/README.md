# Pathfinder GM Rolls

Desktop-first React prototype for a Pathfinder 2e GM group-roll tool.

## Run

npm install
npm run dev

## Stack

React + Vite + Material UI + MUI Icons. Material UI provides the ready-made React components, theming and responsive layout used here. See https://mui.com/material-ui/.

## UX

- Select skill, DC and primary rollers.
- Configure optional Aid Another relationships.
- Aid checks never appear as independent result rows.
- Click a primary result to reveal its roll composition and Aid details.
- Characters, history and settings views are included.
- All data is sample/in-memory and ready to replace with backend calls.
